# 06 · 报表类二开对象：一个结构性的探测盲区

> 起因：一次真实的排障——某用户驱动的 agent 想查一张二开报表(生产进度类，
> 形如"物料进度跟踪表"，具体 form_id、账套、凭据均已脱敏/不适用于本记录)，
> 反复尝试 `GetSysReportData` 的参数组合十几次，全部报同一个错，
> 最终改走浏览器 UI 兜底。整理成本记录是因为**这个坑与账套无关，
> 任何调用报表类二开对象的人都会撞上**，值得让探测器把话说清楚，
> 而不是让下一个 agent 重新走一遍同样的瞎试。

## 现象

- 普通单据（`SAL_SaleOrder`、`PRD_MO` 这类）用 `ExecuteBillQuery` 一查就通；
- 二开**报表**（金蝶后台"报表"菜单下的自定义报表，不是单据）走的是
  **另一个端点** `GetSysReportData`，`ExecuteBillQuery` 对它无效——
  不管这个账号有没有权限，`ExecuteBillQuery` 都会报错，因为它压根
  不是一张"单据"；
- `GetSysReportData` 需要真实的 `FieldKeys`（报表列的 Key）和
  `Model`（过滤参数，含组织等）——这些 Key 因报表而异，`QueryBusinessInfo`
  对自定义报表往往只返回极简元数据（没有列定义），猜不出来；
- 参数不对（哪怕只是留空）时，金蝶给的是一个 **.NET
  `ArgumentNullException`** 风格的通用错误，形如：

  ```
  值不能为 null。
  参数名: key
  ```

  这个错误**不会说"没权限"，也不会说"表单不存在"**——它是服务端内部
  字典查找失败时的原样异常，与是否有权限无关，只取决于参数给得对不对。

## 这对本项目的探测器意味着什么

`base/probe.py` 的 `probe_connection()`（含"嗅探到本体不认识的表单"那条
兜底路径）此前**只试 `query()`**（也就是 `ExecuteBillQuery`）。对一张
真实存在、账号也确实有权限的报表，探测器会得到一个**看起来像"表单不存在"
的业务错误**——因为它问错了端点，不是账号没权限。

**这是一个结构性盲区，不是权限判断的启发式覆盖不全那种"措辞没猜对"**：
`ExecuteBillQuery` 从设计上就不可能查到报表，无论把权限关键词列表扩到
多长都补不上。

## 现在怎么处理（务实，不过度承诺）

探测器**不会去猜 `FieldKeys`/`Model`**——猜错的参数和真实的权限问题
给出的是同一种错误外观，硬猜只会把"不确定"伪装成"确定"。它做的是更
保守的一件事：`query()` 判定为业务错误后，追加用空参数试一次 `report()`。
如果响应是上面那种 `ArgumentNullException` 形状（关键词：`参数名` +
`key`/`null`），说明请求已经进了 `GetSysReportData` 的处理逻辑——
这本身就是"这大概率是个真实存在的报表"的信号，归类为 `possible_report`，
**不算"确认可用"**（没有真实 FieldKeys 就验证不了完整权限），但至少把
"这是报表、别再当单据查"这件事说清楚，不用重新摸索一遍。

## 真要把这张报表接进来，该怎么做

1. 打开报表页面，浏览器 F12 → Network，筛选 `GetSysReportData` 请求；
2. 从请求体里抄出真实的 `FieldKeys`（报表列 Key，逗号分隔）和
   `Model`（过滤参数，通常含组织 `FOrgId`/日期区间/单据号过滤字段等，
   具体键名以抓包为准，不同报表、不同版本可能不同）；
3. 用这组真实参数手动调一次 `report()` 验证读得通、结果符合预期；
4. 报表这类对象目前**不在** `registry.yml`/`profile.yml` 的 `nouns`
   覆盖范围内（`nouns` 段是为 `ExecuteBillQuery` 类单据设计的字段集），
   接入方式是在调用方自己的脚本/工具里直接持有这组 `FieldKeys`/`Model`，
   而不是指望 `kd_object`/`kd_query` 这类通用工具能認得它。

## 一句话版本

**报表用 `GetSysReportData`，单据用 `ExecuteBillQuery`，两者不是同一个
东西的两种用法，是两个完全不同的查询体系。** 拿到一个陌生的 form_id
查不通时，先确认它是单据还是报表——报表报的"参数错误"和真的没权限，
外观上很像，但原因完全不同。
